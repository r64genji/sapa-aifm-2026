# Deliverables — master checklist

One folder per deliverable in the [AIFM guide](../docs/reference/AIFM_2026_Student_Challenge_Guide_All_Challenges.pdf). Each folder's `README.md` has:

1. **Requirement** — quoted from the guide, with the page. This is the only part that is official.
2. **What goes in this folder** — the files we hand in or keep as evidence.
3. **Tasks** — our own plan for meeting the requirement (not an organiser rule). Tick boxes as you go.
4. **Definition of done** — how we know it's finished.

Update the **Status** column here *and* the status line at the top of the folder's README when something moves.

## What judges see on the day

The guide asks for three things on pitch day: **slides (10), a live demo (11) and the pitch with Q&A (12)**. Everything else above feeds into those three. The prototype (03) is what the demo shows; 04–09 are what the slides and Q&A must prove.
