## Rules for the build

- Tests only for rules R1–R42 and bug fixes. Every test is end to end, as set out in 05 "Testing Decisions": a real user action (a Telegram update to the webhook, an HR or manager request with a real session, a Cron call) sent over HTTP to the running production build, on a real local Supabase loaded with the seed sample data. Fake only two outside services, each as a local HTTP server: the model API and the Telegram Bot API. No calls to our own functions from tests, no fakes of our own code. Break each rule by hand once to prove its test fails. "Done" means the test command ran and its last line is pasted in the report.
- Never put a real model key in automated tests.
- Synthetic data only. Seed, eval and handbook data are written as data files, not generated by a model.
- Bahasa Malaysia text is a draft from the dossier; flag it for native-speaker review.
