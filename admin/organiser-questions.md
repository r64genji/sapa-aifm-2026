# Questions for the organisers

The AIFM guide doesn't cover any of these. **Nothing here is an official requirement until it's answered** — write the answer, who answered, and how (email, WhatsApp, website, briefing) next to each item.

| Question | Answer | Source and date |
| --- | --- | --- |
| Dates: registration close, build period, pitch day, more than one judging round? | | |
| Submission: must slides, a prototype link, source code, a video or a written report be uploaded? Where, what format, by when? | | |
| Demo: is a recorded demo accepted as a fallback? (Judging says "convincing live demo".) | | |
| Equipment: is a screen, projector or phone mirroring provided? | | |
| Team and eligibility: team size, student status, one entry per person? | | |
| Topic-selection form: its fields and deadline? | | |
| May the guide PDF be kept in a public GitHub repo? (Only matters if this repo is public.) | | |
